WAR SIMULATOR v4.0 — README
ОПИСАНИЕ
WAR SIMULATOR v4.0 — это автономный 2.5D-симулятор военных действий в браузере. Две армии (Украина и Россия) сражаются на procedurally-генерируемом поле боя с использованием ИИ-алгоритмов тактики, разрушаемым ландшафтом, системой классов и специальными способностями.

Игра работает полностью в одном HTML-файле. Не требует сервера, установки или интернет-соединения. Открыл в браузере — играешь.

ТРЕБОВАНИЯ
Любой современный браузер (Chrome, Firefox, Edge, Opera, Safari)

Клавиатура + мышь

Разрешение экрана от 1024×768 (оптимально 1366×768 и выше)

ЗАПУСК
Сохрани код в файл с расширением .html (например, war_simulator.html)

Открой его двойным кликом в любом браузере

Игра запустится автоматически — две армии начнут сражаться

СИСТЕМА УРОВНЕЙ
Юнит получает уровень за 3 убийства

При повышении: +30 HP, +30% урона, +8% меткости

Над юнитом появляется золотая звезда ★

ИИ-АЛГОРИТМ
Каждый юнит управляется конечным автоматом с 6 состояниями:

Состояние	Описание
advance	Наступление к вражескому флагу
attack	Сближение и атака выбранной цели
retreat	Отступление при низком HP и морали
flank	Фланговый обход с синусоидальным движением
defend	Защита своего флага, патрулирование
capture	Захват центральной точки
Дополнительные ИИ-механики:

Поиск укрытий при низком здоровье

Медики автоматически ищут и лечат раненых союзников

Приоритет целей: ближайший враг > вражеский флаг

Реакция на застревание (прыжок)

Адаптивная смена тактики каждые 0.4–1.4 секунды

ИГРОВЫЕ МЕХАНИКИ
Точка захвата
Находится в центре карты (отмечена флагом ⚑)

Захватывается, когда юниты находятся рядом

Полоса показывает прогресс: синий = UA, красный = RU

Полный захват точки = мгновенная победа

Разрушаемый ландшафт
Укрытия (15 штук) — уничтожаются взрывами

Здания (3 штуки) — имеют полосы здоровья, окна, двери

Воронки — остаются после взрывов на 20 секунд

Погодная система
Погода	Эффект
☀️ Ясно	Стандартная видимость
🌧️ Дождь	Капли, небольшое снижение видимости
⛈️ Гроза	Сильный ветер, много капель, тёмное небо
Погода меняется автоматически каждые 200–600 секунд.

Система морали
Каждый юнит имеет скрытый параметр морали (0.35–1.0)

При морали < 0.35 и HP < 20% юнит отступает

Влияет на выбор между атакой и отступлением

Частицы крови при попадании

Частицы земли при промахе

Частицы смерти (22 шт.)

Частицы лечения (зелёные, 12 шт.)

Частицы огня (14 шт.)

Трассеры пуль (пунктирные линии)

Дульные вспышки

Вспышки попадания (белый спрайт)

Анимация смерти (поворот + затухание)

Анимация ходьбы (покачивание)

Дымовые завесы (расширяются со временем)

Взрывы с ударной волной

Градиентное небо с солнцем

МИНИ-КАРТА
Находится в правом нижнем углу

Отображает: юнитов, здания, укрытия, флаги, точку захвата, дымы

Синие точки = Украина, красные = Россия

Жёлтые = флаги, белая = точка захвата
